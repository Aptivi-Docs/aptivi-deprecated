# ZIP-commands-for-KS

### Brief overview of ZIP shell

The ZIP shell, invoked by `zipshell`, is one of the shells available in the kernel that provides you basic ZIP functions.

### All ZIP commands

1. \[\[cdir|KS ZIP Command cdir]]: Gets current local directory for this shell.
2. \[\[chadir|KS ZIP Command chadir]]: Changes archive directory.
3. \[\[chdir|KS ZIP Command chdir]]: Changes local directory.
4. \[\[get|KS ZIP Command get]]: Extracts a file.
5. \[\[list|KS ZIP Command list]]: Lists files.

For more information about every command, click the command.
