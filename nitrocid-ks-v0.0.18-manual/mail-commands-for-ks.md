# Mail-commands-for-KS

### Brief overview of mail shell

The mail shell, invoked by `lsmail`, is one of the shells available in the kernel that provides you basic mail functions, such as reading mail, reading encrypted mail, sending mail, listing mail, and so on. It supports folder management.

### All mail commands

1. \[\[cd|KS Mail Command cd]]: Changes directory to another mail folder.
2. \[\[exit|KS Mail Command exit]]: Exits the mail shell and returns to shell.
3. \[\[list|KS Mail Command list]]: Lists messages. You can use page number to navigate your messages.
4. \[\[lsdirs|KS Mail Command lsdirs]]: Lists directories.
5. \[\[mkdir|KS Mail Command mkdir]]: Makes a mail directory
6. \[\[mv|KS Mail Command mv]]: Moves a message to another directory.
7. \[\[mvall|KS Mail Command mvall]]: Moves all messages from a specified sender to another directory.
8. \[\[read|KS Mail Command read]]: Reads a message.
9. \[\[readenc|KS Mail Command readenc]]: Reads an encrypted message. You should have the sender's GPG public key.
10. \[\[ren|KS Mail Command ren]]: Renames a directory.
11. \[\[rm|KS Mail Command rm]]: Removes a message.
12. \[\[rmall|KS Mail Command rmall]]: Removes all messages from a specified sender.
13. \[\[rmdir|KS Mail Command rmdir]]: Removes a mail directory
14. \[\[send|KS Mail Command send]]: Sends mail.
15. \[\[sendenc|KS Mail Command sendenc]]: Sends encrypted mail. You should have your own private key, and the recipient should have your public key.

For more information about every command, click the command.
