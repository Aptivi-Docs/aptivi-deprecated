# ⌨️ SpeedPress

<figure><img src="https://github.com/Aptivi-Stable-Docs/nks-manual-0.1.0-beta1/blob/main/.gitbook/assets/image%20(52).png" alt=""><figcaption></figcaption></figure>

You can test yourself finding a specific key in your keyboard, but how fast can you find a key? Find out by playing this game to enter the test.

## Controls

* `Any key`: Submit a key
* `ESC`: Exit the game
