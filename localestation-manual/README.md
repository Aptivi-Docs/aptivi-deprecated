# Welcome

{% hint style="danger" %}
We are no longer supporting LocaleStation due to performance issues with Windows Defender for large applications, such as Nitrocid KS. We will be updating all applications and libraries to use the standard .NET resources file for localizations. We will release a tool that allows you to do this with the release of [**Aptivi Development Toolkit (ADT)**](https://app.gitbook.com/u/NJBwSOFlA3NSfbZMFAYByn83f803).
{% endhint %}

LocaleStation is a code generator for C# and .NET applications that allows them to have a string translation function without having to use satellite assemblies. It uses JSON as the translation data to store information about the localized strings for each language.
