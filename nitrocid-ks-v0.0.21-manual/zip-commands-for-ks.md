# Brief overview of ZIP shell

The ZIP shell, invoked by `zipshell`, is one of the shells available in the kernel that provides you basic ZIP functions.

For more information about every command, click the command.

## All ZIP commands

| Command                             | Description                                  |
| ----------------------------------- | -------------------------------------------- |
| \[\[cdir\|KS ZIP Command cdir]]     | Gets current local directory for this shell. |
| \[\[chadir\|KS ZIP Command chadir]] | Changes archive directory.                   |
| \[\[chdir\|KS ZIP Command chdir]]   | Changes local directory.                     |
| \[\[get\|KS ZIP Command get]]       | Extracts a file.                             |
| \[\[list\|KS ZIP Command list]]     | Lists files.                                 |
| \[\[pack\|KS ZIP Command pack]]     | Packs a local file to the archive.           |
