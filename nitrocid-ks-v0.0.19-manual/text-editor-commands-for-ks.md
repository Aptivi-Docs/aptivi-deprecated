# Text-Editor-commands-for-KS

### Brief overview of text editor shell

The text editor shell, invoked by `edit`, is one of the shells available in the kernel that provides you basic text editing functions.

### All mail commands

1. \[\[addline|KS Text Editor Command addline]]: Adds a new line.
2. \[\[clear|KS Text Editor Command clear]]: Clears the text file.
3. \[\[delcharnum|KS Text Editor Command delcharnum]]: Deletes a character.
4. \[\[delline|KS Text Editor Command delline]]: Deletes a line.
5. \[\[delword|KS Text Editor Command delword]]: Deletes a word.
6. \[\[exit|KS Text Editor Command exit]]: Exits the shell with saving.
7. \[\[exitnosave|KS Text Editor Command exitnosave]]: Exits the shell without saving.
8. \[\[print|KS Text Editor Command print]]: Prints the current text contents.
9. \[\[querychar|KS Text Editor Command querychar]]: Queries a character.
10. \[\[queryword|KS Text Editor Command queryword]]: Queries a word.
11. \[\[replace|KS Text Editor Command replace]]: Replaces a word or phrase in the entire text file.
12. \[\[repalceinline|KS Text Editor Command repalceinline]]: Replaces a word or phrase in the specified line.
13. \[\[save|KS Text Editor Command save]]: Saves changes to a text file.

For more information about every command, click the command.
