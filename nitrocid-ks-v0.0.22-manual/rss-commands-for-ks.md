# Brief overview of RSS shell

The RSS shell, invoked by `rss`, is one of the shells available in the kernel that provides you basic RSS functions, such as reading mail, listing mail, and so on.

For more information about every command, click on the command.

## All RSS commands

| Command                                         | Description                   |
| ----------------------------------------------- | ----------------------------- |
| \[\[articleinfo\|KS RSS Command articleinfo]]   | Gets the article information. |
| \[\[bookmark\|KS RSS Command bookmark]]         | Bookmarks the current feed.   |
| \[\[chfeed\|KS RSS Command chfeed]]             | Changes the RSS feed.         |
| \[\[feedinfo\|KS RSS Command feedinfo]]         | Gets the feed information.    |
| \[\[list\|KS RSS Command list]]                 | Lists articles.               |
| \[\[listbookmark\|KS RSS Command listbookmark]] | Lists all bookmarked feeds.   |
| \[\[read\|KS RSS Command read]]                 | Opens a link to the article.  |
| \[\[unbookmark\|KS RSS Command unbookmark]]     | Unbookmarks the current feed. |
